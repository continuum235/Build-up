# build-up

Basic Expo React Native app for a job and profile onboarding flow. The app includes welcome, auth, profile setup, language, skills, hourly rate, and job discovery screens.

## Figma

https://www.figma.com/design/CVwIhr6rSFajjV8DZv7U4A/Untitled?node-id=3-143&t=BxoDOjgn66cKADA5-1

## Project Structure

- `my-app/` - Expo application source
- `my-app/src/screens/` - app screens
- `my-app/src/navigation/` - navigation setup
- `my-app/src/context/` - shared app state
- `my-app/src/localization/` - translations and i18n setup

## Getting Started


Requirements:

- Node.js
- npm
- Expo Go app or an Android/iOS simulator

Install dependencies:

```bash
cd my-app
npm install
```

Start the development server:

```bash
npm start
```

Run on a specific platform:

```bash
npm run android
npm run ios
npm run web
```
